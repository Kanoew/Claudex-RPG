# Polices de l’interface

- **Barlow Regular** : dialogues et commandes.
- **Barlow Condensed SemiBold** : titres et noms des personnages.

Créées par Jeremy Tribby, distribuées sous la licence SIL Open Font License 1.1.
Fichiers originaux, sans modification, provenant de [Google Fonts](https://github.com/google/fonts) :
[`ofl/barlow`](https://github.com/google/fonts/tree/main/ofl/barlow) et
[`ofl/barlowcondensed`](https://github.com/google/fonts/tree/main/ofl/barlowcondensed).
Les licences complètes sont conservées dans ce dossier.

Les deux fichiers de police pèsent environ 209 Kio au total. Ils sont chargés depuis
le jeu, sans requête vers un service de polices. Si leur chargement échoue, le
navigateur affiche les polices de secours définies dans `polish.css`.
