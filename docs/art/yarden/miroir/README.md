# Yarden — visage pour la scène du miroir

[Portrait PNG transparent](visage.png), 1205 × 1306 pixels. [Aperçu sur damier](index.html). Source de travail rapprochée, de face, préparée à la demande de Jordan pour la première découverte de son visage. Yeux bleu-gris, peau pâle, lunettes rondes dorées, gros chignon noir à mèches gris-lavande, maquillage violet sombre. Expression calme et observatrice. Sans boucle d’oreille ni collier.

Ce portrait ne montre ni la salle de bain ni un reflet ; ne pas le retourner pour fabriquer une autre vue. Il ne représente pas la révélation des tatouages ou de la marque du flanc. Le raccordement à la scène après l’appartement reste à faire ; cette grande source n’est pas chargée par le moteur. Préparer un export réduit avant son usage dans un dialogue mobile.

Pour la suite D, invocation et coup de base de la faux sont désormais gratuits ; Fauchage reste à 20 mana. Le combat et les libellés sont modifiés dans la même branche, avec des tests de régression.
